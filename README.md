# TWERG-HoneyBot (Discord 蜜罐防護機器人)

TWERG-HoneyBot 是一個專為 地牛記錄小組 (TWERG) 及合作伺服器設計的雙重蜜罐與自動化防禦機器人。

邀請網址：https://discord.com/oauth2/authorize?client_id=633683077180293120

---

## 使用方式（伺服器管理員指南）

如果您是合作伺服器的管理員，加入並設定 HoneyBot 共同防禦惡意破壞者的步驟如下：

### 1. 啟用與授權
1. 邀請機器人進入您的 Discord 伺服器。
2. 聯絡機器人擁有者核准您的伺服器（未授權伺服器機器人將不會開啟防護功能）。

### 2. 伺服器權限與身分組設定
請確保機器人在您的伺服器中具備以下權限（務必二次確認，Discord 官方邀請網址漏了禁言權限...）：
* **檢視頻道**
* **踢出、核准和拒絕成員**
* **對成員停權**
* **禁言成員**
* **傳送訊息和建立貼文**
* **管理訊息**
* **嵌入連結**
* **跳過慢速模式**
* **讀取訊息歷史**

建議將機器人的身分組順序調整至 **「伺服器管理員以下、普通成員以上」**，以避免機器人被惡意濫用。

---

### 伺服器管理員指令

僅限擁有 **「伺服器管理員 (Administrator)」** 權限的使用者調用：

* **`/設定`**：開啟圖形化防護與系統設定面板。
  * **白名單與身份組**：設定免疫機器人自動懲罰的白名單身份組，以及 `@提及` 即自動 BAN 的陷阱身份組。
  * **惡意帳號與門檻**：調整發言監控畢業門檻 (預設 10 次)、嚴格防護模式 (潛水與新用戶加強監控，已畢業老成員維持豁免)、**跨伺服器聯防封鎖 (`sync_ban`)** 與 EEW 速報暫停。
  * **伺服器防護日誌**：指定本伺服器的獨立事件日誌紀錄頻道。
* **`/發言統計`**：查看本伺服器目前新用戶發言次數與嚴格防護模式狀態。
* **`/手動畢業`**：手動將發言未達門檻的可信成員標記為已畢業（豁免後續新用戶監控）。

---

### 處決通報卡片與快捷按鈕操作

當系統偵測到違規（黑名單、大字體洗板、圖片洗板、違規關鍵字/正則、標記保護對象）時，會在頻道與日誌發送處決通報卡片，並附帶管理員快捷按鈕：

* 🔨 **停權（全域）**：將用戶於本伺服器封鎖，寫入全系統惡意帳號黑名單庫。若有開啟聯防，會**同步預先封鎖至其他開啟聯防的伺服器**。
* 👋 **踢出**：將用戶踢出本伺服器。
* 🔓 **解除禁言**：誤判時供管理員一鍵解除 3 天 Timeout 禁言。

---

### 信任人員專屬指令 (Owner & Trusted Users)

由機器人擁有者授權的「信任人員」可使用以下高級聯防指令：

* **`/幹男`**：查看、新增或刪除全系統惡意破壞者帳號黑名單 (`bad_users`)。
* **`/保護對象`**：查看、新增或刪除受害者與重點保護對象名單 (`target_users`)。
* **`/聯防封鎖`**：輸入惡意用戶 ID，手動對全系統所有開啟聯防的伺服器發起 **ID 預先封鎖 (Pre-ban)**。

## 核心防禦機制

1. **EEW 地震速報連動暫停**：速報發布時自動暫停洗板檢測 3 分鐘，避免強震時成員熱烈討論被誤判。
2. **幹男惡意帳號黑名單**：比對黑名單帳號，一發言即刻刪除訊息並執行 3 天禁言。
3. **受害者標記防護**：新用戶前 N 筆訊息若顯式 `@` 標記保護對象，立刻刪除並禁言 3 天。
4. **圖片/附件洗板防護**：60 秒內連續發送 5 則圖片/附件，自動執行 1 小時禁言。
5. **Markdown 大字體洗板防護**：新用戶使用 `#` 大字體洗板或組合騷擾，自動執行 3 天禁言。
6. **短時間高頻發言防護**：新用戶 5 秒內發送超過 3 則訊息，直接判定為惡意灌水洗板並禁言 1 小時（保留訊息供核查）。
7. **新用戶重複內容防護**：新用戶 30 秒內連續發送相同內容，自動禁言 1 小時（保留訊息）。
8. **純符號與純表情過濾**：排除純符號、純標點與純表情訊息，不計入畢業門檻累加。
9. **敏感詞與正則比對**：具備繁簡歸一化與全半角轉換，自動比對粗口恐嚇與正則特徵並禁言 3 天。

## 專案架構

您也可以選擇自行部署，若無特殊需求則不建議（因為共同聯防資料庫就不會互通）。

```text
TWERG-HoneyBot/
├── bot.py                     # 主程式入口，負責掛載 Cogs 與指令同步
├── config.json                # (需手動建立) 環境設定檔
├── guild_settings.db          # (自動生成 SQLite) 伺服器防禦模組、門檻與身份組設定庫
├── server_authorizations.db   # (自動生成 SQLite) 伺服器授權許可紀錄庫
├── counts.db                  # (自動生成 SQLite) 活躍發言監控計數庫
├── counts_archive.db          # (自動生成 SQLite) 畢業歸檔發言紀錄庫
├── ryker_badusers.db          # (自動生成 SQLite) 惡意帳號 (bad_users) 與受害者 (target_users) 庫
├── trusted_users.json         # (自動生成 JSON) 信任人員名單檔
├── ryker_keywords.py          # 違規敏感詞庫、正則特徵與預設保護對象
├── README.md                  # 說明文件
├── cogs/                      # 模組化 Cog 指令與監控
│   ├── about.py               # /關於 機器人宣告指令
│   ├── console_output.py      # Console 控制台日誌轉發模組
│   ├── counts.py              # /發言統計 指令模組
│   ├── defense.py             # 核心防禦監控 Cog 與黑名單/聯防控制
│   ├── graduate.py            # /手動畢業 指令模組
│   ├── guilds.py              # /伺服器列表 擁有者監控模組
│   ├── heartbeat.py           # 機器人心跳維護模組
│   ├── honeypot.py            # 蜜罐頻道處決模組
│   ├── owner.py               # 擁有者專屬管理指令模組
│   ├── server_check.py        # 新伺服器加入審核通報模組
│   ├── settings.py            # /設定 伺服器面板指令模組
│   └── trap_roles.py          # 陷阱身份組防禦處決模組
├── defense_modules/           # 7 大獨立防禦演算法模組
│   ├── defense_bad_users.py   # 黑名單帳號比對
│   ├── defense_bad_words.py   # 敏感詞與正則特徵比對
│   ├── defense_eew.py         # 地震速報連動暫停
│   ├── defense_header_spam.py # 大字體洗板比對
│   ├── defense_image_spam.py  # 圖片洗板比對
│   ├── defense_target_users.py# 保護對象標記比對
│   └── defense_text_spam.py   # 高頻發言、重複內容比對與符號過濾
└── settings/                  # UI 設定面板子視圖模組
    ├── settings_main.py       # 主設定面板
    ├── settings_roles.py      # 白名單與陷阱身份組設定
    ├── settings_bad_users.py  # 惡意帳號防範開關與門檻設定
    ├── settings_log.py        # 本伺服器獨立日誌頻道設定
    ├── settings_honeypot.py   # 蜜罐頻道狀態檢視
    └── settings_utils.py      # 資料庫讀寫工具
```
